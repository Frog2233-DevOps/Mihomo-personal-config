# Отчёт о интеграционном тестировании (23.11.2026)

[English version](TEST-REPORT.md)

## Окружение

Реального железа не было, поэтому тесты шли на **настоящей QEMU-эмуляции платы
Cudy WR3000S v1**, а не на имитации парсера конфига:

| | |
|---|---|
| Эмулятор | `github.com/stavultras/router-emulator` v4.1, машина `mt7981-router` |
| Источник | тема 4pda 1087457, пост #10376; папка прошивки `nand-wr3000s` из архива на Яндекс.Диске по той же ссылке |
| Гость | OpenWrt 25.12.5, ядро 6.12.94, aarch64, 256 МБ RAM, overlay 84,8 МБ |
| Хост | aarch64, mihomo Meta v1.19.33 (та же версия, что и цель проекта) |
| Тестовая подписка | локальный HTTP-сервер с пятью нодами: две зарубежные, одна российская, одна LTE, одна инфо-нода «Traffic remaining» |

Официальный веб-эмулятор Cudy (`support.cudy.com/emulator/WR3000S`) проверен
и отвергнут: он только симулирует веб-интерфейс стоковой прошивки и не может
запустить OpenWrt, OpenClash или mihomo.

Чтобы запустить headless на этом хосте, пришлось обойти поставляемый
загрузчик эмулятора (он не мог привязать Unix-сокет монитора QEMU); сама
машина загрузилась нормально.

## Находки (все воспроизведены до исправления)

| # | Проблема | Факт, который её доказал | Важность |
|---|---|---|---|
| 1 | `normalize()` в `build-ruleset.sh` использовал `^[A-Za-z0-9_.]+$` и терял все домены с дефисом и punycode | 20 833 из 82 146 строк RKN, 66 из 714 community, 8 373 из 110 923 anti-AD на списках от 23.11.2026. Пересборка старым скриптом дала **побайтово тот же** `rkn-blocked.mrs` (SHA256 `3145bf8d…`), что и закоммиченный | высокая: заблокированные сайты не блокировались |
| 2 | `fix-exec.sh` / `.ps1` копировали устаревшие `automation/*.yml` поверх `.github/workflows/*.yml` | Запуск описанного в README «фикса» откатывал env `MIHOMO` и `bash ./scripts/deploy.sh` | средняя: CI молча терял правки |
| 3 | `deploy.sh` передавал в `scp` ssh-опцию `-p <порт>`, а у `scp` `-p` означает «сохранить время» | `scp: stat local "8022": No such file or directory` при `ROUTER_PORT=8022` | высокая: деплой невозможен на нестандартном порту |
| 4 | Проверка `scp -O` (`scp -h | grep -- '-O'`) никогда не срабатывала | `ash: /usr/libexec/sftp-server: not found` на роутере | высокая: деплой невозможен с OpenSSH 9+ |
| 5 | `build-ruleset.sh` считал байты через GNU `stat -c%s` | Сборка на роутере печатала `Bytes: 0` для каталога на 1,8 МБ | низкая: ложная информация |
| 6 | `check-groups.sh` считал ответ 401 валидным | Все группы печатались как `NOT FOUND`, после чего оба предупреждения ложно писали `OK` | высокая: ложное «всё хорошо» |
| 7 | У `check-groups.sh` fallback на `uclient-fetch` использовал `-o` вместо `-O` и не передавал Authorization | Без curl нельзя получить авторизованный ответ | средняя: сломанный резервный путь |

Находки 1 и 2 уже исправлены в `dev` PR #4 до этого круга; находки 3-7
обнаружены при прогоне на эмуляторе и исправлены здесь.

## Исправления

* `scripts/deploy.sh`: `-p` для `ssh`, `-P` для `scp`; `do_scp()` сначала
  пробует `-O` и откатывается к обычному `scp` для старых клиентов.
* `scripts/build-ruleset.sh`: подсчёт байтов через POSIX `wc -c`.
* `scripts/check-groups.sh`: отвергает любой ответ без `"proxies"`; fallback
  `uclient-fetch` использует `-O` и передаёт Bearer-токен.
* `tests/`: новый регрессионный набор, подключённый к
  `.github/workflows/validate.yml` (и его копии в `automation/`), чтобы CI
  запускал его на каждом PR.
* Доки: EN/RU-версии installation/design/README обновлены; в устранение
  типичных проблем добавлены все новые находки; в `AGENTS.md` — правила 13-15
  и команды запуска тестов.

`scripts/selftest.sh` с реальным ядром тоже проходит. Часть
`tests/run-all.sh` без роутера — теперь 130 проверок; опциональный цикл на
роутере добавляет ещё 13.

Установщик также ставит ежедневное обновление в crontab роутера при
`ROOT=/etc/openclash` (или `ENABLE_CRON=1`). GitHub-воркфлоу только коммитит
новые rule-set'ы в репозиторий — секретов доступа к роутеру здесь нет, поэтому
без cron на устройстве списки оставались бы навсегда устаревшими. Проверено с
заглушкой `crontab` (чужие строки сохраняются, дублей нет) и на живом эмуляторе:
после двух установок осталась одна строка `update-rulesets.sh`.

## Установщик одной командой

`scripts/install.sh` добавлен потому, что гайд описывал каждый шаг, но не было
одной команды, которая их выполняет. Скрипт работает на роутере под POSIX
`sh`: скачивает конфиг, файл перезаписи, четыре скрипта, свой список доменов и
все 28 `.mrs` во временный каталог, подставляет URL и пароль, а затем ставит
всё в раскладку OpenClash. Он сохраняет пользовательский список доменов,
копирует изменённый конфиг в `.bak`, никогда не печатает учётные данные и не
меняет текущую конфигурацию, если какая-то загрузка не удалась.

Дополнительно проверена работа без прав root с нестандартным `ROOT`.

Проверено дважды: `tests/07_install.sh` с локальным HTTP-сервером (35 проверок,
включая `|`, `&` и `\` в учётных данных и все три варианта) и на живом
эмуляторе с `BASE_URL`, указывающим на хост. Прогон на роутере поставил все 28
rule-set'ов, записал `secret: testpass` и URL подписки без искажений, пометил
скрипты исполняемыми и пропустил `mihomo -t`, потому что в тестовом каталоге
ядра не было.

### Что проверено на живом эмуляторе

* mihomo v1.19.33 загрузил 28 провайдеров / 252 793 правила; RSS 37 МБ на
  пяти нодах.
* Запрос к `01-klinika-21.ru` в логе: `match RuleSet/rkn-blocked` — домен с
  дефисом теперь действительно блокируется.
* `check-groups.sh`: зарубежные ноды в `🚀 Auto` / `⚡ Turbo` / `🔁 Failover`,
  российская — только в `🎯 Manual`, LTE и «Traffic remaining» — нигде.
* `update-rulesets.sh APPLY=reload`: пересобрал все 28 rule-set'ов своим ядром
  на роутере, поставил их и перечитал конфиг через `PUT /configs?force=true`
  без перезапуска.
* Неверный пароль дашборда: `check-groups.sh` теперь выходит с кодом 1 и
  явной ошибкой вместо ложного `OK`.
