# Группы прокси

[English](GROUPS.md) | **Русский**

18 групп. Эмодзи — часть имени: названия одинаковые в конфиге, в правилах и
в дашборде.

## Вход

| Группа | Тип | Содержимое | Зачем |
|---|---|---|---|
| `🎯 Final` | select | `🚀 Auto`, `⚡ Turbo`, `🔁 Failover`, `🎯 Manual`, `DIRECT` | Группа, на которую указывает последнее правило (`MATCH`). Это переключатель, которым пользуются каждый день. |

## Автоматические

Все три исключают российские ноды и ноды LTE / info.

| Группа | Тип | Настройки | Зачем |
|---|---|---|---|
| `🚀 Auto` | url-test | tolerance 50 мс, 300 с | Обычный выбор: самый быстрый нод, который держит стабильность. |
| `⚡ Turbo` | url-test | tolerance 0, 120 с | Переключается быстрее и держится за самый быстрый нод даже при небольшой разнице. Для игр и видеозвонков. |
| `🔁 Failover` | fallback | 300 с | Держит первый ответивший нод и переходит дальше только когда тот умирает. Самый стабильный, самый негибкий. |

В smart-варианте `🚀 Auto` — это группа `smart`: она взвешивает ноды по своим
собственным замерам, а не только по задержке.

## Ручной выбор

| Группа | Тип | Содержимое | Зачем |
|---|---|---|---|
| `🎯 Manual` | select | все ноды подписки, включая российские, кроме LTE / info | Выбрать один конкретный нод. Эта группа заменила прежнюю `RU Nodes`: российский выход по-прежнему в один клик. |

## Сервисные

Каждая — это `select` с одними и теми же тремя вариантами: `🚀 Auto`,
`🎯 Manual`, `DIRECT`. Ставьте `DIRECT` для сервиса, который работает без
прокси, и `🎯 Manual` — для сервиса, которому нужен конкретный нод.

| Группа | Rule-set | Примечание |
|---|---|---|
| `💬 Telegram` | `telegram` | Telegram смотрит только на exit IP, российский подходит. |
| `🎮 Discord` | `discord` | Discord блокирует российские IP, держите его на зарубежном ноде. |
| `🤖 AI` | `openai`, `anthropic`, `google-gemini`, `xai` | Зарубежные AI-сервисы. Российские (`category-ai-ru`) идут напрямую. |
| `▶️ YouTube` | `youtube` | |
| `🎬 Streaming` | `netflix` | |
| `🐙 GitHub` | `github` | |
| `📱 Social` | `instagram`, `facebook`, `twitter` | |
| `🎮 Steam` | `steam` | |
| `🧱 Roblox` | `roblox` | |
| `🕹️ Games` | `category-games` | Игры, у которых нет своего списка. |

Эти группы стоят **перед** списком РКН намеренно: Telegram, Discord и
AI-сервисы есть и в списке РКН (13, 22 и 15 пересекающихся доменов). Если
правило РКН окажется первым, выбрать нод для них станет недостижимо.

## Особые

| Группа | Тип | Содержимое | Зачем |
|---|---|---|---|
| `🌐 CDN` | select | `🚀 Auto`, `🎯 Manual`, `DIRECT` | Хостнеймы CDN крупных провайдеров. Переключите на `DIRECT`, чтобы сэкономить трафик, или на конкретный нод. |
| `⭐ Custom` | select | `🚀 Auto`, `🎯 Manual`, `DIRECT` | Домены из `lists/custom-domains.list`. Правило этого списка стоит **выше** списка рекламы и выше списка РКН: ваше решение важнее любого списка. |
| `🚫 RKN Blocked` | select | `🚀 Auto`, `🎯 Manual`, `REJECT`, `DIRECT` | Домены, которые блокирует РКН и у которых нет своей сервисной группы. `REJECT` отрезает их полностью, `DIRECT` пропускает без блокировки. |

## Как наполняются группы

Группы с `use: [Main]` берут ноды подписки и применяют к ним свои фильтры:

* `🎯 Manual` использует `noise-filter`: выкидывает LTE-серверы и info-ноды
  подписки (счётчики трафика, срок действия, тарифы).
* `🚀 Auto`, `⚡ Turbo` и `🔁 Failover` используют `foreign-filter`: то же
  самое, плюс российские ноды. Российский exit-IP ничего не разблокирует,
  поэтому он ломал бы ровно те сайты, ради которых этот конфиг и существует.

Фильтры живут на группах и никогда на провайдере: OpenClash переписывает
фильтры провайдера из своего интерфейса.

Проверить результат на роутере — `scripts/check-groups.sh`.
